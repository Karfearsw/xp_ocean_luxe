# Ocean Luxe Estate — Discord VIP Portal (Client Experience)

## Purpose
- Replace scattered SMS/email threads with a premium, organized “trip command center.”
- Provide real-time itinerary updates, confirmations, and concierge coordination.
- Create an optional VIP community layer (Estate Society) without mixing with active trip ops.

## Server structure (recommended)
### Categories
- Welcome
  - #start-here (rules + concierge SLA + how to get help)
  - #announcements (major updates only)
- Active Trips (private)
  - One private channel per trip (or per household)
- Estate Society (optional)
  - #member-lounge
  - #orlando-drops
  - #ask-the-concierge (managed hours)

## Roles
- Ocean Luxe Admin (full)
- Concierge (ops)
- Dispatcher (transport)
- Trip Designer (planning)
- Partner (restricted, optional; rarely used)
- Client (default)

## Client trip channel template (pinned)
- “Your concierge rules” (hours, escalation, emergency rules)
- “Today’s plan” quick view
- Itinerary link + document folder link
- Pickup manifest (when transport is included)
- Confirmation codes (redacted where appropriate)

## Concierge SLA (example)
- Standard: responses within X business hours
- VIP: responses within X minutes during support window
- Emergency: phone escalation protocol (defined)

## Privacy boundaries (non-negotiable)
- No sharing of sensitive financial data in Discord.
- Limit personal data in channel history; store in platform system of record.
- Remove/lock trip channels after completion; archive notes to CRM.
