- Book a Concierge Consult

- Hero: “Effortless Orlando, Estate-Level Service”
- Proof: outcomes, testimonials, trust marks

4) **Transportation**

## Funnel Paths (MVP)
### Path A: High-intent buyer (paid search)
Landing page → Trip Snapshot → Consult booked → Deposit → Itinerary production → In-trip concierge → Review + referral → VIP Club → Westgate invite (qualified)

### Path B: Partner referral (villa manager / Airbnb host)
Referral landing page → Consult booked (short) → Package proposal → Deposit → Execution → Referral flywheel

### Path C: Corporate
Corporate page → Discovery call → Quote + SLA → Contract + invoice → Execution → Retainer renewal

### Path D: Westgate (invitation only)
Value content → “Request Invitation” → Qualification + consent → Review/approval → Education call → Handoff to Westgate process → Outcome tracked → Post-handoff nurture
